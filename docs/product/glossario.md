# Glossário

**Status:** Vocabulário de domínio confirmado, exceto itens explicitamente abertos.

| Termo | Definição |
| --- | --- |
| `CrmWorkspace` | Agrupador de processos de CRM. Pode possuir diversos pipes. |
| `CrmPipe` | Fluxo configurável dentro de um CrmWorkspace. |
| `CrmStage` | Etapa configurável de um pipe. |
| `CrmCard` | Unidade visual e processual do CRM. Orquestra referências, não substitui fatos comerciais versionados. |
| `Opportunity` | Contexto de negócio comercial conduzido no CRM. |
| `Offering` | Produto ou serviço ofertável pela iJúnior. Não é sinônimo de escopo. |
| `SizingAssessment` | Avaliação versionada de viabilidade, complexidade, esforço, equipe, sprints, riscos e premissas. |
| `CommercialScope` | Escopo negociado no Comercial antes de se tornar baseline de projeto. |
| `Pricing` | Estrutura de precificação relacionada a oportunidade, dimensionamento e proposta. |
| `Proposal` | Oferta comercial com versão, status e histórico próprios. |
| `Accepted Proposal` | Proposta aceita que fundamenta a formalização de um contrato. |
| `Contract` | Instrumento criado e formalizado no Comercial. Após assinatura válida, é fato compartilhado imutável in-place. |
| Handoff | Passagem habilitada por assinatura válida para preparar Project Workspace sem redigitação. |
| `ScopeBaseline` | Registro inicial do escopo contratado no contexto de Projetos. |
| `ScopeVersion` | Evolução controlada de baseline após Change Request. |
| `ChangeRequest` | Mecanismo para mudança de escopo, valor, prazo contratual ou critério. |
| `Project` | Unidade operacional de Projetos. Não existe “projeto financeiro” como agregado distinto. |
| `ProjectTask` | Unidade de execução operacional de um projeto. Não altera, por si só, o escopo contratado. |
| `PaymentPlan` | Plano financeiro derivado das condições aplicáveis do contrato. |
| `Installment` | Parcela financeira com valor, vencimento, situação e histórico de liquidação. |
| `FinancialTransaction` | Movimentação financeira que registra entrada, saída, ajuste, estorno ou liquidação. |
| `FinancialSummary` | Projeção de leitura financeira. Não é fonte de verdade. |
| `Partner` | Parceiro compartilhado relacionado a contratos e projetos. |
| `PartnerRule` | Condição financeira ou de repasse específica de uma relação de parceria. |
| `PlatformPrivilege` | Privilégio administrativo explicitamente atribuído e auditável. |
| `legacy_complexity_score` | Dado histórico de migração. Não é métrica canônica de novos registros. |

## Termos ainda abertos

- Nomes normativos de estados de oportunidade, proposta, contrato, projeto, sprint, task, parcela e fechamento.
- Taxonomia de contrato, documento fiscal, obrigação, parceria e regras de repasse.
